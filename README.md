# 悦山公寓运营系统

一个面向小型公寓的 Django Web 应用。核心思路是以“房间”为中心管理房态、人员、合同、流水台账和导出报表；Excel 只作为初始化导入和对外导出，不再作为主数据源。

## 快速启动

```powershell
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py runserver 0.0.0.0:8000
```

电脑浏览器打开 `http://127.0.0.1:8000/`。手机和电脑在同一内网时，用电脑内网 IP 加端口访问。

### 项目位于 WebDAV / RaiDrive 时

SQLite 数据库不适合直接放在 WebDAV、RaiDrive、NAS 等远程挂载盘上，可能出现 `database is locked`。代码可以继续放在远程盘，但建议把数据库文件放在电脑本地，例如：

```powershell
$env:APARTMENT_DB_PATH="$env:LOCALAPPDATA\YueshanApartment\db.sqlite3"
New-Item -ItemType Directory -Force (Split-Path $env:APARTMENT_DB_PATH) | Out-Null
python manage.py migrate
python manage.py runserver
```

如果远程盘中的 `db.sqlite3` 已经有正式数据，请先停止程序，再把它复制到上述本地路径，然后运行。不要在程序运行期间复制 SQLite 数据库。

## 从零开始

新公寓不需要先做 Excel。进入网页后可以直接：

- 在 `房间` 页面新增房间，维护房号、挂牌价、佣金基数、密码、固定费用等信息。
- 在房间详情页签约、上传自主申报二维码、添加常住人/暂住人/管理员、记录流水、退租、换房。
- 在 `人员` 页面新增或修改人员；新增人员时直接选择房间和入住类型。
- 在 `流水` 页面统一录入 `收`、`付`、`应收`、`应付`，用来补充系统自动流程覆盖不到的情况。

## 导入模板

首页点击 `下载导入模板` 会得到三张核心表：

- `房间与合同`：一行一间房，可同时填当前主租客和合同。
- `入住人员`：一人一行，用房间号关联，适合多人同住、暂住、管理员。
- `期初账务`：一行一笔接管当天的待收待付或已收已付。

填好后首页点击 `导入表格` 上传。历史旧账和旧合同建议不迁入系统，只录当前真实状态和从今天开始需要管理的信息。

如需清空业务数据重新开始：

```powershell
python manage.py clear_business_data --yes
```

## 日常入口

- `房间`：最主要入口，按每间房查看和操作全部信息。
- `签约`：只显示空房；签约时佣金基数来自房间，可用实际佣金覆盖。
- `账单`：分为待收和待付。待收按房间和月份合并房租、取暖费，支持全额或部分收款；结清后仍保留蓝色记录。
- `收付款`：方向是 `收` 或 `付`，可选择款项类型 `押金`、`租金`、`其它`。
- `新增账单`：方向可选 `收`、`付`、`应收`、`应付`；选房间时自动关联该房间当前合同，并进入流水页。
- `刷新账单`：生成未来约 31 天内的房租、取暖费、佣金等自动待处理流水。
- `导出中介房态`：生成 PNG 图片，只展示空房和 30 天内到期房。
- `导出警务报备`：生成当前在住人员 Excel。

## 首版边界

- 当前使用 SQLite，适合本地电脑或家中内网服务器；数据库文件应放在本地磁盘。
- 公网部署前应切换 PostgreSQL，并配置 HTTPS、强密码、备份和访问控制。
- 身份证、电话属于敏感信息，不建议在未加权限和 HTTPS 的情况下公网暴露。
- OCR、身份证照片识别、合同照片识别后续可以作为“导入草稿”流程接入。
